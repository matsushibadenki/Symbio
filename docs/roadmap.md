# Symbio roadmap

直近は、複数文書を同時保持するRust管理基盤とGUI切替を実装しました。次は成熟した外部CASへの接続と、研究結果の再現性を高める機能を優先します。

## 01 · 共通表現とデスクトップ基盤

- 🟢 [Done] Rust所有のSEG、不変ノードの構造共有、パーサー、前提条件、限定的な次元検査。
- 🟢 [Done] 提供された数学キーボードのキー配列を再利用。計算用テンプレート・選択範囲挿入・入力Undo/Redo・メモ用LaTeXパレット。
- 🟢 [Done] LaTeX部分文法をRustでSEGへ解析。編集中のMathMLプレビュー、メモから計算セル作成、同一カーネルで計算・保存・復元。
- 🟢 [Done] LaTeXの積分・有限和／積・添字・行列・等式をSEG化。キーボードの入力枠移動、MathML組版、拡大表示、意味を保持した入力形式変換。
- 🟢 [Done] Tauri 2 WebView UI、数式編集・MathML表示、英語／日本語／简体中文、情報ツールチップ。
- 🟢 [Done] 数式・結果を先に読むノート構成、選択セルへの操作集約、原文編集の開閉、変数別の数値入力、参照元／参照先を優先するインスペクター。オブジェクト／参照選択と中央ノートのスクロールを連動。
- 🟢 [Done] ATOM由来のドック／タブ／ネイティブフローティング、配置とウインドウ位置の保存。
- 🟢 [Done] revision付き操作API、JSONL CLI、文書保存、外部変更検知、編集下書き保護。
- 🟢 [Done] 明示的なセル参照、依存グラフの選択・拡大表示、式と前提条件の変更時の部分再計算、計算条件・エラーの保存と復元。
- 🟢 [Done] 依存グラフからのセル原文編集、Expression／LaTeX変換、数式プレビュー、数学キーボード、適用時の部分再計算。別パネルとの編集競合・未適用下書きを保護。
- 🟢 [Done] 全分岐・計算結果を保持するSEGの不要ノード回収。自動回収、上限到達時の再試行、手動回収、使用中／未使用ノード数の表示。
- 🔴 [Later] SEGの部分式を直接選択する構造編集と、依存グラフ上の接続編集。
- 🟢 [Done] ネイティブのファイル選択／Save As、現在の保存先表示、最後に開いた文書の復元。未保存変更・下書き・ファイルロック・外部変更を保護し、文書世代で古い更新を拒否。
- 🟢 [Done] 「開く」の左に空の文書の新規作成ボタン。保存先を持たない文書、初回保存先の選択、未保存変更の保護、⌘/Ctrl+N。
- 🟢 [Done] 最大16文書の同時保持とGUI切替。文書ごとの未保存変更・Undo/Redo・ファイルロック、開いたファイルの重複防止、保存確認付きの文書クローズ、非表示文書も対象にした終了保護。
- 🟠 [Next] MathJSON/OpenMathの意味を保つ交換。
- 🔴 [Later] 開いている全文書のセッション復元・一括保存・クラッシュ回復。

## 02 · 計算と信頼性

- 🟢 [Done] 記号評価・厳密部分代入・数値化を分離。有理数の代入条件を保存し、依存変更時に再計算。特異値・前提違反・未対応の次元付き代入を拒否。
- 🟢 [Done] 自然な定義・参照の組版、明示モデルの入力／出力分離、自由パラメータの未指定ドメイン表示。限定的な独立SymPy比較と数学的契約の文書化。
- 🔴 [Later] 検証可能な導出証明書、7基本次元と単位系、テンソル・非可換代数、誤差伝播、科学図版のベクター出力。
- ⭕️ [Pending] Rubi全体および提案された高度物理問題のCAS横断検証。対応する演算基盤の実装後に評価。

- 🟢 [Done] 整数・有理数の厳密演算、条件付き簡約、単変数多項式の展開・微分・積分、一部初等関数の微分。
- 🟢 [Done] float64数値評価、記号処理と近似の区別、エンジン・前提・精度の記録。
- 🟢 [Done] ThreeX/wgpuによるRust内の1024点プロット。GPUデータ／フレームをJSへ転送しない。
- 🟢 [Done] 定積分・不定積分の限定的厳密計算、8×8までの行列演算、有理係数二次方程式の実数解。
- 🟠 [Next] 成熟したCASアダプターによる因数分解・一般方程式・一般積分。条件付き等価変形の回帰テスト拡充。
- 🟢 [Done] 中央のノート／3Dタブと分割可能な3D曲面パネル。Rust/wgpuの陰影付きメッシュ、回転・ズーム・範囲変更、セル／前提変更時の更新、ドック／フローティング。
- 🟢 [Done] 3Dの独立したx/y範囲、x/y/zラベルと元の値を示す軸目盛り、回転・ズームに追従する表示。
- 🟠 [Next] 3Dの適応サンプリング、複数曲面の比較。既存の2Dプロットのドック統合。
- 🔴 [Later] eggによる資源制限付き最適化、FLINT/MPFR、保証付き数値、複素数・大規模行列・テンソル。
