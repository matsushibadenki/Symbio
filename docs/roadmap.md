# Symbio roadmap

直近は、MathJSON／OpenMathの行列式・転置の交換を実装しました。LaTeXや参照セルから作った演算を原式のまま保持し、再読み込み後も既存Rustカーネルで厳密計算します。次は交換形式の拡張、一般CAS演算、承認可能なAI提案を優先します。
